# 🎮 DEVIL'S TERMINAL - SERVER v1.0 🚀

Welcome to the core backend engine of the **GAMER ONLY** Secure Chat Application. This repository hosts the lightweight, high-speed Python server designed to handle real-time multiplayer text streaming with low latency.



---

## ⚡ Core Features
* **Multi-Client Support:** Handles multiple gamers connecting simultaneously from anywhere in the world.
* **Custom Profile Engine:** Decodes and syncs unique Usernames and Gaming Avatars (👾, 💀, 👽, 🤖, 👑).
* **System Broadcasts:** Automatic alerts when players join or leave the lobby.
* **Cloud Ready:** Optimized with dynamic port binding for seamless deployment on 24/7 hosting platforms like Render or PythonAnywhere.

---

## 🛠️ Tech Stack & Architecture
* **Language:** Python 3.12+
* **Core Modules:** `socket`, `threading`, `os`
* **Architecture:** Multi-threaded TCP/IP Server
